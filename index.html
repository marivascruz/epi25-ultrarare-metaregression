4B. Relationship Between Ultra-Rare Unified M7 −log10(p-value), Explained Variance (R²), and Gene Size (Amino Acids, LAA) at AF ≤ 0.0001

Across 67,022 ultra-rare gene–phenotype tests at AF ≤ 0.0001, canonical protein length LAA correlates linearly with ultra-rare coding variant count Mg (r = +0.908, ≈0.239 variants/AA), while exhibiting virtually zero correlation with −log10(pM7) (Pearson r(log10AA) = +0.0915, Spearman ρ = +0.0707) and an inverse critical variance law R²crit(LAA) ≈ 31.8 / (0.239 LAA + 27.8) where compact synaptic and channel genes (≤800 AA) achieve massive variance explained (R² = 20–64%).
